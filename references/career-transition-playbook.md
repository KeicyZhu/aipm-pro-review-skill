# Career Transition Playbook

Use this reference when the user is moving from another function into AI Product Management.

## Universal Bridge

Every background can be translated through this chain:

```text
Original work -> User/problem insight -> Product mechanism -> AI capability -> Metric/evaluation loop
```

Example:

```text
Campaign operations -> user segmentation -> configurable lifecycle triggers -> AI recall assistant -> activation/retention metrics
```

## Marketing to AI PM

Transfer:

- Audience segmentation
- Positioning
- Competitive analysis
- Funnel thinking
- Campaign metrics

Package as:

- AI scenario discovery
- Value proposition definition
- GTM for AI features
- User insight-driven roadmap
