# AI PM Capability Map

Use this reference when tailoring a user's experience to a target AI Product Manager role.

## Core AI PM Capabilities

| Capability | Evidence to look for | Safe wording |
|---|---|---|
| Agent / Workflow | Flowcharts, tools, task routing, state transitions, fallback rules | Designed or decomposed an AI workflow |
| Prompt Engineering | Prompt versions, few-shot examples, constraints, negative examples | Built structured prompt rules and regression cases |
| Model Evaluation | Test sets, QA labels, Bad Cases, human review rubrics | Defined evaluation dimensions and feedback loops |
| SFT Data Loop | Corrected outputs, labels, sample rules, eval sets | Defined product-side SFT standards and sample selection |
| RAG / Memory | Knowledge sources, context rules, retrieval logic, memory update rules | Designed context and knowledge retrieval mechanisms |
| A/B Experiment | Variables, cohorts, metric trees, experiment results | Designed experiments and decision metrics |
| Multimodal / AIGC | Image/audio/video workflows, prompt specs, review standards | Defined content generation workflow and quality criteria |
| Data Analysis | Spreadsheets, SQL, dashboards, cohort analysis | Built insight loops and metric-driven decisions |
| Commercialization | Pricing, payment, entitlement, conversion, user value | Connected AI experience to business model |
| Launch / Risk | Gray release, rollback, monitoring, safety rules | Defined launch and risk-control criteria |

## JD Keyword Clusters

- Agent: workflow, tool calling, orchestration, memory, routing, intent recognition.
- Evaluation: benchmark, annotation, Bad Case, eval set, regression, human review.
- Prompt: few-shot, CoT, structured output, constraints, style, negative examples.
- SFT/LoRA: sample mining, labels, train/eval split, acceptance metrics, adapter, rollout.
- Growth: A/B test, funnel, retention, conversion, activation, cohort.
- AIGC: multimodal, image generation, video generation, content pipeline, review.

## Interview Defense

If challenged on exaggeration:

- Clarify your actual role.
- Explain the product-side contribution.
- Describe how you collaborated with technical teams.
- Separate completed work from proposed next steps.
- Return to evidence and metrics.
