```text
Use AIPM-Pro Review to rewrite this project into 4 AI Product Manager resume bullets. Emphasize Agent workflow, model evaluation, Prompt Engineering, and A/B experiments. Do not exaggerate ownership.
```

## Career Transition

```text
I come from operations and want to apply for AI Product Manager roles. Here is my project history. Use AIPM-Pro Review to identify transferable capabilities, rewrite my experience, and prepare interview stories.
```

```text
I did not personally train a model, but I worked on prompts, evaluation, Bad Cases, and corrected outputs. Use AIPM-Pro Review to package this as product-side SFT standard definition and explain how I would coordinate LoRA/SFT with algorithm engineers.

```
